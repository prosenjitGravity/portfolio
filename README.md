# 🌌 Prosenjit Paul • Gravity UI & macOS Interactive Portfolio

> *Welcome to zero-gravity engineering! An interactive, macOS-inspired desktop operating system built right inside the browser with Angular 19, custom glassmorphism, dynamic animations, and retro terminal power.*

---

## ✨ Features & Fun Interactive Modes

### 🪐 1. Gravity UI Desktop (macOS Sequoia Experience)
* 🪟 **Real Window Manager:** Drag, resize, layer (`zIndex`), minimize, and maximize floating windows with realistic macOS titlebar physics.
* 🚀 **Interactive Dock:** Responsive dock with tooltip magnifications, active dot indicators, and instant app launchers.
* ⌨️ **Live Hacker Terminal:** Built-in shell simulator supporting commands like `matrix`, `neofetch`, `skills`, `exp`, `projects`, `clear`, and `help`.

### 📸 2. Photo Booth (Leica Camera Engine)
* 🔴 **Iconic Leica Filters:** Authentic Leica Look, Leica M-Monochrom (Deep B&W), and Leica Vivid tones.
* 🍎 **Mac Studio Looks:** Studio Portrait Glow, Noir, and Cyber Frost filters.
* 🏷️ **Dynamic Telemetry Watermark:** Burns camera optics (`LEICA M11-P • 35mm f/1.4`), live IP address, GPS telemetry (`22.57°N 88.36°E`), and timestamps onto your snapshots.
* 🔒 **Smart Hardware Auto-Shutoff:** Camera turns off automatically when switching windows, minimizing, or blurring tabs for complete privacy.

### 📜 3. Dual Mode: Gravity Desktop ⇋ Classic Portfolio
* Switch instantly between the interactive macOS desktop environment and a streamlined, responsive single-page scrolling layout at any time with one click.

## 🛠️ Tech Stack & Architecture

* **Framework:** Angular 19 (Standalone Components)
* **Language:** TypeScript 5.6+
* **Reactive Core:** RxJS & Angular Signals
* **Styling:** Vanilla SCSS, CSS Custom Properties & Glassmorphism Blur
* **Icons:** Font Awesome 6.7
* **Testing:** Jasmine, Karma & Playwright

## 🚀 Quickstart & Local Run

```bash
# 1. Clone the repository
git clone https://github.com/prosenjitGravity/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
ng serve
```
Open `http://localhost:4200` to launch the Gravity UI desktop.
